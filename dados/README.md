# Dados

Seis tabelas cruas do capstone de fraude (Pós-Graduação em Data Science e IA, disciplina de SQL):
`transacoes`, `scores_comportamentais`, `scores_financeiros`, `scores_modelo`, `dim_paises`, `dim_categorias`.
Chave das tabelas de transação: `id_transacao`. Os CSVs não são versionados.

**Origem:** material fornecido pelos professores do curso (pasta "Base de Dados - Capstone de Fraude").
**Como recarregar:** coloque os 6 CSVs nesta pasta e rode `make db` na raiz (cria `fraude.db` em SQLite).
**Licença:** conferir os termos de uso antes de qualquer publicação dos dados; por isso eles ficam fora do repositório.
